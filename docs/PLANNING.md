## XP-практики

- **TDD** — для кожної story спершу коміт `red` (падаючий тест), потім `green` (мінімальний код),
  за потреби `refactor`.
- **Парне програмування** — пари вказані мітками `pair-XY` у Jira.
- **Малі релізи** — git-теги `v0.1`, `v0.2`, `v1.0` наприкінці кожної ітерації.
- **Спільний стандарт коду** — `ruff` + `black`, line-length 100.
- **Колективне володіння кодом** — сервіси (`app/services`) є чистими функціями з параметром `now`.
- **Неперервна інтеграція** — `pytest` проганяється перед кожним комітом `green`.

## Формат комітів

`SVL-<номер>: <red|green|refactor> — <що зроблено>`. Ключ Jira в повідомленні зв'язує коміт
із задачею (інтеграція GitHub for Jira).
