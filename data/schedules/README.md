# Формат графіків (spike SVL-13)

Оператор публікує графік як таблицю «черга → інтервали відключень на добу». Нормалізуємо в JSON:

```json
{"date": "2026-10-13", "queues": {"1": "08:00-12:00, 16:00-20:00", "6": ""}}
```

- інтервали — час **відключення**, розділені комою або `;`;
- `24:00` означає кінець доби, інтервал на кшталт `22:00-02:00` перетинає опівніч;
- порожній рядок — відключень немає;
- графік вважається добовим шаблоном, що повторюється, доки не імпортовано новий.

`today.json` — базовий графік, `changed.json` — оновлення, де змінено чергу 3.
